# Social copy playbook (from BlackTwist social-media-skills, 2026-11-18)

Distilled from the 14 `*-sms` skills in `../../social-media-skills/` (MIT). Use it for everything
**around** the video: the hook line, on-screen text, caption, title/description, carousel cut-down,
series framing, repurposing plan and the post-mortem on how it did.
**Where it conflicts with `platforms.md`, `platforms.md` wins** (newer, sourced) — see §9.

---

## 1. Voice profile first (social-media-context-sms)
One persistent profile per brand, captured once, read before writing anything:
identity + one-line positioning · audience (pain, goal, sophistication, where they hang out) ·
3–5 voice adjectives, **verbatim phrases to use / avoid**, formality, humour level · 3–5 pillars with
a *unique angle* each · per-platform goal + frequency · preferred/avoided formats ·
**3–5 real example posts copied verbatim** (most important for voice matching) · anti-patterns
(topics, tones, content types).
→ For our brands, keep this in the brand's `brand.json` / brief. Capture the user's own words, not a summary.

## 2. Hook library — 9 patterns (hook-writer-sms)
Contrarian · Question · Story opener · Statistic/data · List preview · Bold claim · Empathy ·
Before/After · Confession (+ "curiosity gap" for video).
- Generate **5–7 variants, each labelled with its pattern**, mark ★ one pick with a one-line reason.
- Self-check: would *you* stop for it if you hadn't written it? Does it open a question the piece
  answers? Is it specific enough that it couldn't belong to anyone else's post?
- Precise numbers beat round ones; vague stories lose; performative vulnerability backfires.
- **Video hooks are 3 aligned surfaces**: spoken line (first 1–2 s), on-screen text (**≤ 6 words**,
  clear of UI), caption line 1. Reels trick: on-screen hook and caption hook promise *different*
  angles ("3 mistakes I made" / "the one I'm most embarrassed about ↓").
- YouTube long-form: title + thumbnail + first 5–8 s; restate the title's promise with stakes in the
  first 5 s (30-s retention is a ranking signal). Clickbait the video doesn't pay off is punished.
- Best patterns by platform: TikTok/Shorts = curiosity gap, contrarian, list, confession, story;
  Instagram = curiosity gap, list, story, before/after, confession; LinkedIn = story, stat,
  before/after, empathy; X = contrarian, bold claim, question, confession; YouTube titles = stat,
  before/after, list, contrarian; Pinterest = keyword "how to / ideas for / best X for Y" (no contrarian).
- A/B: same body, change only the first 1–2 lines, 2–3 weeks apart, compare **rates** not raw
  counts; judge hooks by save rate, comment:like ratio, profile visits.

## 3. Caption anatomy (caption-writer-sms)
**Hook (before truncation) → Payoff → one platform-native CTA.** The visual stops the scroll; the
caption closes the loop. First decide the visual's role (hook / proof / punchline) — the caption
fills the role the visual doesn't. Never just describe what's on screen.
- For Reels/TikTok/Shorts the caption is supporting copy: a punchline, a CTA, or **a search keyword
  the video never says out loud**.
- Native CTAs: IG "Save this for later" / "Send to the friend who…" / "Comment X for the link";
  TikTok "Follow for part 2" / "Try this and tag me"; Facebook an open question; YouTube
  "Subscribe for [specific value]" + watch-next; Pinterest none (the pin is the asset).
- Lengths: IG Reel 100–300 chars (feed 80–300, carousel 200–800), ~125 visible; TikTok mostly
  < 150; Facebook 40–80 for photos, 300–500 for stories, ~120 visible on mobile; YouTube title
  60–70 chars, description hook in first ~150 chars then chapters + links; Shorts caption < 150.
- Pinterest = search engine: title ≤ 100 (keyword first, no emoji), description ≤ 500, link in the
  link field, natural keywords not hashtags, 2:3 imagery.
- YouTube long-form > ~3 min: chapters in the description; pin a top comment for the main CTA.
- Write IG alt text. Never copy one hashtag set across platforms.
- Voice match from examples: vocabulary, punctuation habits (em dashes, lowercase), emoji habit,
  sentence rhythm, emotional register.

## 4. Text posts that ride along with a video (post-writer-sms, platform-strategy-sms)
- White space rule: **never more than 2–3 lines without a blank line**.
- LinkedIn: 1,200–1,500 chars, hook in 1–2 lines before "see more", line break every 1–2
  sentences, no link in body (first comment), ends with a direct question, 3–5 hashtags.
  Signals: dwell time > comments (incl. your own replies) > first 60–90 min > saves.
- X: < 280 chars, 0–2 hashtags; replies > quote posts > bookmarks > likes; first 30 min matter.
- Threads: texting-a-smart-friend tone, polish is suspicious, 0–1 hashtag, 500 chars.
- Bluesky: 300 chars, anti-corporate, keywords for custom feeds, no promo in the first 20–30 posts.
- Same voice, different register per platform (examples in platform-strategy-sms "Tone Adaptation").
- CTA by content type: educational "What would you add?", story "Has this happened to you?",
  promo "Link in comments / DM me [word]", personal "Anyone else?".

## 5. Carousels — the cut-down of a reel (carousel-writer-sms)
Cover (headline + subtitle, earns the swipe) → Context (1–2 sentences of pain) → Body (**one point
per slide, header ≤ 8 words, body ≤ 30 words**, end each slide on a micro-cliffhanger) → CTA
(one-line summary + one action). Write the cover **last**.
Formats: Listicle · Framework (named, numbered) · Before/After contrast · Data storytelling ·
Mini case study (Problem → Approach → Result → Lesson).
Specs: IG 8–10 slides, 4:5 1080×1350, loop last slide to first; LinkedIn 7–12 (PDF doc post),
denser text OK; Facebook 5–8, 1:1; TikTok photo mode 6–12, 9:16, **≤ 6 words on-image**, add
trending audio; Pinterest Idea Pin 6–10 pages, 9:16, page 1 = keyword cover.
Slide copy carries the value; the caption sets up the swipe and closes with the CTA — don't duplicate.

## 6. Series / Part 1–N (thread-writer-sms)
- Every part must **hook and pay off on its own** — never assume Part 1 was seen.
- Label "Part X" in on-screen text **and** caption line 1 **and** the voiceover.
- Pin Part 1 to the profile; consistent thumbnail/cover style; one series-specific hashtag
  (e.g. `#linkutmglossary`); YouTube = playlist + end-screen to next part, name parts
  "[Series] — Part X: [topic]".
- "Reply to comment" videos as the next part compound reach; Community post between drops
  ("What should Part 3 cover?").
- Pacing: vary length, short palate-cleansers between dense beats, don't resolve the core insight
  early. Pick the format first: listicle · story arc (setup → conflict → resolution → lesson) ·
  named framework · breakdown of a real example · contrarian (claim → common belief → evidence →
  nuanced restate).

## 7. Repurposing one video (content-repurposer-sms)
1. Extract **3–7 standalone insights** (claim + example + who it's for); rank by "if someone saw
   only this, worth it?" Top one = anchor derivative.
2. Insight → format: process → carousel/thread; counterintuitive claim → standalone/opener;
   story → thread/long LinkedIn; stat → standalone with context; framework → carousel; quote → quote post.
3. Leverage order: **vertical clip (one asset → Reels + TikTok + Shorts, three captions)** > X thread >
   LinkedIn post > carousel > YouTube long-form > Pinterest > Threads > Facebook > quote posts > Community.
4. Spread over 5–7 days, ≥ 24 h apart, anchor first. Never "I made a video about…" — post the insight natively.
→ Pairs with `playbook-clipping.md` (long → shorts) and `platforms.md` exports.

## 8. Strategy, calendar & analytics (content-strategy / calendar / performance / growth / pattern / optimization)
- Pillar mix default: educational 30 · storytelling 25 · personal 20 · engagement 15 ·
  **promotional ≤ 10–15** (lead-gen goals shift budget to storytelling/educational, not promo).
  Topics tagged **cornerstone** (deep, authority) vs **supporting** (quick, reach).
- Calendar: no pillar > 40 % of slots, no active platform silent > 3 days, heavy pieces not stacked
  on one day, **20–30 % of slots left open** for reactive/trend content. Batch by platform.
  Weekly 15-min review + monthly recalibration.
- Analytics: always **engagement rate** = (likes + comments + reposts + saves) / impressions × 100,
  benchmarked against the account's **own** average, never industry averages. ≥ 5 posts for a
  per-post read, ≥ 15 (ideally 30) for patterns. Flag recency bias on fresh posts.
- Pattern dimensions: topic/pillar · format · time · length · hook type · tone · platform →
  "Do More / Do Less / Experiment With" + one key takeaway. Untested winning combos
  (top pillar × top format) = experiments.
- Growth: engagement (existing followers) ≠ follows (discovery). Spike = ≥ 2× average daily follows
  → find the post behind it. Add a follow CTA to breakout posts.
- Recommendations in 4 tiers: quick wins (< 1 h, cite a data point) → strategic shifts (2–4 weeks,
  state the trade-off) → experiments (hypothesis / test / success / failure criteria) → stop doing
  (+ do instead). Max 10 items, one "#1 priority", state confidence when the sample is thin.
